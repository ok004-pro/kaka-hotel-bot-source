# 더스테이클래식명동호텔 관리단 카카오 챗봇 연동 매뉴얼

현재 송이님 PC에서 카카오톡 챗봇용 실시간 API 서버가 외부 인터넷 도메인으로 개장되어 있습니다.

## 1. 현재 서버 정보

- 로컬 서버: http://127.0.0.1:8000
- 외부 터널 홈 주소:
  https://tsch-hotel-bot-2026.localtunnel.me
- 카카오 i 오픈빌더 스킬 URL:
  https://tsch-hotel-bot-2026.localtunnel.me/chatbot/skill

## 2. 브라우저 테스트 결과 의미

- 홈 주소(`/`) 접속 시:
  "카카 호텔 관리단 챗봇 서버 정상 작동" 페이지가 보이면 성공입니다.

- `/chatbot/skill` 주소를 브라우저에서 열면:
  `status: ok`, `method_for_kakao: POST` 안내 JSON이 보이면 성공입니다.

- 실제 카카오 서버는 브라우저처럼 GET으로 여는 것이 아니라 POST로 호출합니다.
  POST 테스트도 정상 완료되었습니다.

## 3. 카카오 i 오픈빌더 스킬 등록 절차

1. 카카오 i 오픈빌더 또는 챗봇 관리자센터 접속
2. 챗봇 생성 또는 기존 챗봇 선택
3. 왼쪽 메뉴에서 [스킬] 클릭
4. [스킬 생성] 클릭
5. 아래처럼 입력
   - 스킬 이름: 호텔_QNA_투표_서버
   - URL: https://tsch-hotel-bot-2026.localtunnel.me/chatbot/skill
6. 저장 후 [스킬 테스트] 실행
7. 정상 응답이 나오면 저장

## 4. 시나리오/블록 연결

- 폴백 블록: 사용자가 아무 질문이나 했을 때 이 스킬을 호출하도록 연결
- 규약 Q&A 블록: 규약 질문을 이 스킬로 연결
- 대외비 자료 블록: 회의록/수익률/분배금/결산 질문을 이 스킬로 연결
- 투표 블록: "총회 투표하기" 발화 시 이 스킬로 연결

## 5. 주의사항

- 현재 localtunnel은 임시 터널입니다. PC가 꺼지거나 터널 프로세스가 종료되면 접속이 끊깁니다.
- 테스트용으로는 충분하지만, 실제 운영에는 고정 도메인 + 클라우드 서버 배포가 필요합니다.
- 대외비 정보는 테스트 서버에 가짜 샘플 데이터로 넣어두었습니다. 실제 회의록/수익률/분배금 파일을 연결할 때는 접근 권한 설계를 먼저 확정해야 합니다.
